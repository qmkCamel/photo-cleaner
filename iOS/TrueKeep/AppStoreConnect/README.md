# TrueKeep App Store Connect Packet

Updated: 2026-06-11

This folder contains copy-paste metadata for App Store Connect. It is intentionally plain text so the account owner can paste fields manually before any upload automation is introduced.

Use `../SUBMISSION_RUNBOOK.md` before entering these fields in App Store Connect. The runbook lists the required signing, hosted URL, screenshot approval, TestFlight, and final submit gates.

## Metadata

- `metadata/en-US/` - English App Store localization draft.
- `metadata/zh-Hans/` - Simplified Chinese App Store localization draft.
- `review-notes.txt` - App Review notes draft for the current build.
