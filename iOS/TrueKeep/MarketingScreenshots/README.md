# Marketing Screenshot Capture

This folder stores screenshot artifacts captured from the iOS UI test flow.

Latest capture:

- `2026-06-13-1811-photo-video-copy/`: latest photo/video trust-copy simulator screenshot set.
- `2026-06-13-1811-photo-video-copy/raw/`: raw XCTest screenshot attachments exported from the latest screenshot capture result.
- `2026-06-13-1811-photo-video-copy/source-map.json`: mapping from raw attachment filenames to marketing-friendly names.
- `2026-06-13-1811-photo-video-copy/contact-sheet.png`: quick visual contact sheet.

Named screenshots:

1. `01-welcome.png`: local-only trust positioning.
2. `02-permission-rationale.png`: Photos permission rationale.
3. `03-settings-trust.png`: privacy and safety settings.
4. `04-home-review-queue.png`: sample-data review queue.
5. `05-screenshot-review.png`: screenshot review flow.
6. `06-review-bin.png`: Review Bin before deletion.
7. `07-delete-safety-confirmation.png`: delete confirmation and iCloud warning. The sheet uses a large detent to avoid clipped confirmation text in accessibility audits.
8. `08-default-empty-no-fixtures.png`: default launch with fixture-only cards hidden.

Usage notes:

- Screenshots are generated by `TrueKeepUITests/testMarketingScreenshotCaptureFlow`.
- The flow stops at delete confirmation. It does not confirm deletion and does not delete photo or video items.
- `02-permission-rationale.png` describes local review candidates with no-upload and deletion-confirmation safety limits.
- `04-home-review-queue.png` uses internal sample data for design review and UI automation. Real default launch remains covered by `08-default-empty-no-fixtures.png`.
- Visual candidate categories should be described as local, low-confidence review candidates, not automatic deletion decisions.
- The 2026-06-13 photo/video-copy set was captured after focused photo/video copy, video-preview, and accessibility regressions passed.

Re-capture command:

```sh
xcrun simctl status_bar 0157BFC9-C9C9-48DC-845E-AABED7B2DCE9 override --time 9:41 --batteryState charged --batteryLevel 100 --wifiBars 3 --cellularBars 4
xcodebuild test -project TrueKeep.xcodeproj -scheme TrueKeep -destination 'platform=iOS Simulator,id=0157BFC9-C9C9-48DC-845E-AABED7B2DCE9' -only-testing:TrueKeepUITests/TrueKeepUITests/testMarketingScreenshotCaptureFlow -resultBundlePath /absolute/path/to/MarketingScreenshots.xcresult
xcrun xcresulttool export attachments --path /absolute/path/to/MarketingScreenshots.xcresult --output-path /absolute/path/to/exports
```
