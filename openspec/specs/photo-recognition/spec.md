# 照片识别规格

## 目的

照片识别把本地照片库信号转换为 TrueKeep 清理任务中的复核候选。

## 需求

### 需求：扫描只产出复核候选

扫描器必须只产出复核候选，不得自动删除、隐藏或修改用户照片库资源。

#### 场景：检测到视觉发现

- **当** 扫描检测到相似、误拍或模糊视觉发现
- **则** app 将其展示为复核候选
- **并且** 删除仍然必须经过复核箱和二次确认

### 需求：相似照片识别使用有边界的本地视觉信号

扫描器必须在有边界的近期照片分类上限和较短创建时间窗口内，本地识别相似照片。

#### 场景：发现本地相似照片

- **当** 两张或更多非截图照片落在相似时间窗口内
- **并且** 本地视觉信号将它们判定为相似
- **则** 扫描器将它们分组为相似照片复核组
- **并且** 推荐一张保留项，但不得自动删除其他照片

#### 场景：照片超出时间窗口

- **当** 照片视觉信号相似但超出相似时间窗口
- **则** 扫描器不得将它们分组为相似照片

### 需求：质量检测必须保守

扫描器必须把模糊照片和疑似误拍检测作为低置信度复核辅助。

#### 场景：照片质量可能较差

- **当** 本地质量信号显示模糊、曝光极端或画面信息较低
- **则** 扫描器可以创建模糊或误拍复核候选
- **并且** 该候选默认不得被选中删除

### 需求：识别保持本地且有边界

视觉识别必须本地运行，不得请求网络回源的 iCloud 缩略图下载。

#### 场景：本地缩略图不可用

- **当** Photos 无法在不允许网络访问的情况下提供本地缩略图
- **则** 跳过该资源的视觉分类
- **并且** 扫描继续处理其他可用资源
