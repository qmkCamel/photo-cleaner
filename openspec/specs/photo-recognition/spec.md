# 照片识别规格

## Purpose

照片识别负责把本地照片库中的元数据与视觉信号转换为 TrueKeep 清理任务中的复核候选，同时保持本地处理、保守推荐和用户最终确认的产品边界。

## Requirements

### Requirement: 扫描只产出复核候选

扫描器 MUST 只产出复核候选，不得自动删除、隐藏或修改用户照片库资源。

#### Scenario: 检测到视觉发现

- **当** 扫描检测到相似、误拍或模糊视觉发现
- **则** app 将其展示为复核候选
- **并且** 删除仍然必须经过复核箱和二次确认

### Requirement: 相似照片识别使用有边界的本地视觉信号

扫描器 MUST 在有边界的近期照片分类上限和较短创建时间窗口内，本地识别相似照片，并使用系统图片质量与可用的人脸拍摄质量辅助推荐保留。

#### Scenario: 发现本地相似照片

- **当** 两张或更多非截图照片落在相似时间窗口内
- **并且** 本地视觉信号将它们判定为相似
- **则** 扫描器将它们分组为相似照片复核组
- **并且** 推荐一张保留项，但不得自动删除其他照片

#### Scenario: 照片超出时间窗口

- **当** 照片视觉信号相似但超出相似时间窗口
- **则** 扫描器不得将它们分组为相似照片

#### Scenario: 相似组包含可比较的人脸照片

- **当** 相似组成员具有 Vision 人脸拍摄质量结果
- **则** 推荐保留排序应该以总体图片质量为主、人脸拍摄质量为辅
- **并且** 推荐保留项不得自动加入删除选择

#### Scenario: 人脸质量不可用

- **当** 相似组成员没有可用的人脸拍摄质量
- **则** 推荐保留排序必须继续使用总体图片质量

### Requirement: 质量检测必须保守

扫描器 MUST 把系统图片质量模型、模糊照片和疑似误拍检测作为低置信度复核辅助，并保留可解释的本地图像信号。

#### Scenario: 照片质量可能较差

- **当** 本地质量信号显示模糊、曝光极端或画面信息较低
- **则** 扫描器可以创建模糊或误拍复核候选
- **并且** 该候选默认不得被选中删除

#### Scenario: 系统模型给出极低图片质量分

- **当** Vision 图片美学评分极低
- **并且** 图片没有被标记为 utility
- **则** 扫描器可以将模型低分作为疑似误拍的辅助信号
- **并且** 该候选默认不得被选中删除

#### Scenario: 系统模型标记 utility 图片

- **当** Vision 将图片标记为 utility
- **则** 扫描器不得只根据该标记把图片归为疑似误拍或可删除候选

#### Scenario: 系统模型请求失败

- **当** Vision 图片美学评分失败或没有结果
- **则** 扫描器必须回退到现有本地启发式质量信号
- **并且** 单张图片失败不得中断其他资源扫描

### Requirement: 识别保持本地且有边界

视觉识别 MUST 本地运行，不得请求网络回源的 iCloud 缩略图下载。

#### Scenario: 本地缩略图不可用

- **当** Photos 无法在不允许网络访问的情况下提供本地缩略图
- **则** 跳过该资源的视觉分类
- **并且** 扫描继续处理其他可用资源
