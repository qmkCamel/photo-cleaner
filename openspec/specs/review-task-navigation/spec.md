# review-task-navigation Specification

## Purpose
定义首页复核任务到具体分组的稳定导航、预览选择指示器边界和自动化验证要求，确保同分类多任务不会误入其他分组。

## Requirements
### Requirement: 首页任务必须打开对应复核分组

首页每个复核任务 MUST 以唯一任务 ID 定位来源复核分组。存在多个相同分类的任务时，App MUST 打开用户实际点击的分组，不得按分类回退到第一个分组。

#### Scenario: 点击同分类的第二个任务

- **WHEN** 首页存在两个或更多相似照片任务且用户点击第二个任务
- **THEN** 复核页必须显示第二个任务对应的分组和候选
- **AND** 当前复核分组不得变成同分类的第一个分组

#### Scenario: 任务对应分组已经失效

- **WHEN** 用户点击的任务 ID 在当前复核分组中已经不存在
- **THEN** App 必须留在首页且不得打开其他分组
- **AND** 当前分组和候选选择状态必须保持不变

### Requirement: 首页预览不得伪装成可选择控件

首页任务中的缩略图 MUST 只作为任务内容预览，不得展示不可交互的空心选择圆或选中状态。逐张选择指示器 MUST 只出现在支持候选选择的复核界面。

#### Scenario: 首页展示任务预览

- **WHEN** 首页任务卡展示一张或多张候选缩略图
- **THEN** 缩略图不得叠加空心选择圆
- **AND** 点击行为必须继续由整张任务卡承载

#### Scenario: 复核页展示候选

- **WHEN** 用户进入支持逐张选择的复核分组
- **THEN** 可删除候选必须继续显示实际选择状态
- **AND** 推荐保留候选必须继续保持不可加入删除选择

### Requirement: 相同分类任务必须可被唯一自动化定位

每个首页任务 MUST 暴露包含唯一任务 ID 的稳定自动化标识。新增或修改的自动化 MUST 覆盖同分类多任务的精确导航，并以 `keepAlways` 保存首页预览和目标详情的语义命名截图；自动化 MUST 保持真实 Photos 删除禁用。

#### Scenario: 自动化打开第二个相似任务

- **WHEN** 确定性测试状态包含两个相似照片任务
- **THEN** 自动化必须能够通过不同标识定位第二个任务
- **AND** 必须断言详情显示第二组而非第一组
- **AND** 必须保留首页无圆框和第二组详情截图

### Requirement: 复核分组批量选择必须提供双态反馈

复核页 MUST 根据当前分组可选择候选的实际选择状态显示批量操作。推荐保留候选 MUST 始终排除在批量选择之外，批量操作 MUST 只影响当前分组，并且点击结果 MUST 立即反映在候选选择指示器和加入复核箱数量上。

#### Scenario: 当前分组尚未全选

- **WHEN** 当前分组至少有一个可选择候选未被选中
- **THEN** 批量按钮必须显示“全选本组可清理项”
- **AND** 点击后必须选择当前分组全部可选择候选
- **AND** 推荐保留候选必须保持未选择且不可选择

#### Scenario: 当前分组已经全选

- **WHEN** 当前分组全部可选择候选已经选中
- **THEN** 批量按钮必须显示“取消全选”
- **AND** 点击后必须取消当前分组全部可选择候选
- **AND** 加入复核箱按钮必须同步显示零选择状态

#### Scenario: 自动化验证双态结果

- **WHEN** 自动化在禁用真实 Photos 删除的确定性分组中执行取消全选和重新全选
- **THEN** 自动化必须断言批量按钮文案、候选选择和加入复核箱数量发生对应变化
- **AND** 必须使用 `keepAlways` 保留取消全选和重新全选的语义命名截图
