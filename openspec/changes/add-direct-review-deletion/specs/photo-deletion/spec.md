## ADDED Requirements

### Requirement: 复核组必须支持直接删除明确选中的候选

复核组 MUST 提供“加入复核箱”和“直接删除”两个同层级动作。两条路径 MUST 只包含当前明确选中的候选；用户逐张主动选中的推荐保留项 MUST 被视为明确选择。没有可删除选择时两个动作 MUST 同时不可用。

#### Scenario: 用户从复核组发起直接删除

- **WHEN** 用户在复核组中选中一个或多个可删除候选
- **AND** 用户点击“直接删除”
- **THEN** App 必须展示应用内删除确认
- **AND** 确认内容必须说明项目数量、系统照片图库删除、iCloud Photos 同步风险和“最近删除”恢复路径

#### Scenario: 当前没有选中候选

- **WHEN** 当前复核组没有选中可删除候选
- **THEN** “加入复核箱”和“直接删除”必须同时不可用

#### Scenario: 用户主动选择推荐保留项

- **WHEN** 推荐保留候选当前未选择
- **AND** 用户逐张点击该候选
- **THEN** App 必须将其标记为已选择删除
- **AND** “加入复核箱”和“直接删除”的选择数量必须包含该候选
- **AND** 用户再次点击时必须能够取消该选择

#### Scenario: 使用无障碍字号

- **WHEN** 用户使用无障碍 Dynamic Type 查看复核组主操作
- **THEN** “加入复核箱”和“直接删除”必须完整显示且保持可用触控区域
- **AND** 两个动作不得互相遮挡或挤压文字

### Requirement: 直接删除必须满足局部进度和失败恢复约束

直接删除请求 MUST 异步执行，执行期间 MUST 保留当前候选数据并在确认动作上展示局部进度，同时 MUST 阻止重复提交。全部失败或部分失败后，用户 MUST 能够在原复核上下文中重试或调整选择。

#### Scenario: 删除正在执行

- **WHEN** 用户确认直接删除
- **THEN** 确认按钮必须显示删除进行中状态
- **AND** 确认和取消动作必须暂时不可重复触发
- **AND** 当前候选在收到 Photos 删除结果前必须保持不变

#### Scenario: 删除全部失败

- **WHEN** Photos 没有确认任何请求资源删除成功
- **THEN** App 必须保留全部候选和原选择
- **AND** App 必须展示失败原因和可重试路径

#### Scenario: 删除部分成功

- **WHEN** Photos 返回成功资源 ID 和失败资源 ID
- **THEN** App 必须只移除成功删除的候选
- **AND** 失败候选必须继续保留并保持选中
- **AND** App 必须展示成功数量、未完成数量和失败原因

### Requirement: 直接删除完成后必须同步所有受影响状态

直接删除完成后，App MUST 以 Photos 返回的成功资源 ID 为准更新共享扫描状态，MUST NOT 根据请求列表假定全部成功。共享状态 MUST 同步复核组、复核箱、首页任务、预览、预计体积和结构化删除摘要。

#### Scenario: 直接删除后当前组仍有候选

- **WHEN** Photos 确认部分当前候选删除成功且当前组仍有可操作候选
- **THEN** 成功资源必须从当前组和复核箱移除
- **AND** 首页对应任务的数量、预览和预计体积必须只包含剩余候选
- **AND** 当前组的失败或未选择候选必须继续可复核

#### Scenario: 直接删除清空当前组

- **WHEN** Photos 确认当前组全部可操作候选删除成功
- **THEN** 首页不得继续展示该组对应任务
- **AND** 当前复核页必须展示稳定完成反馈而不得跳到其他分组或发生索引越界
- **AND** 用户返回首页时必须立即看到已经同步的结果

#### Scenario: 相同分类存在多个任务

- **WHEN** 用户直接删除同一分类中的一个具体分组
- **THEN** App 必须只更新该分组对应的任务 ID
- **AND** 同分类其他分组及其首页任务必须保持不变

### Requirement: 直接删除自动化必须默认非破坏性

UI 自动化和常规 smoke MUST 默认阻止真实 Photos 删除。确定性成功结果 MUST 仅在 DEBUG 测试配置下可用，并且禁删配置 MUST 继续优先于任何破坏性测试配置。

#### Scenario: 自动化验证直接删除成功

- **WHEN** UI 自动化覆盖直接删除 loading、完成态和首页同步
- **THEN** 测试必须启用真实删除安全锁
- **AND** 成功结果必须由确定性 DEBUG 模拟提供
- **AND** 测试必须保留操作、确认、loading、完成和首页同步的语义命名截图

#### Scenario: 自动化验证直接删除失败

- **WHEN** UI 自动化在安全锁开启时确认直接删除
- **THEN** App 必须报告未删除任何照片或视频
- **AND** 候选和选择必须保留
- **AND** 直接删除动作必须恢复为可重试状态
