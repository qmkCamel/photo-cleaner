## MODIFIED Requirements

### Requirement: 首页预览不得伪装成可选择控件

首页任务中的缩略图 MUST 只作为任务内容预览，不得展示不可交互的空心选择圆或选中状态。逐张选择指示器 MUST 只出现在支持候选选择的复核界面。复核界面的推荐标记 MUST 与待删除选择指示器使用不同语义。

#### Scenario: 首页展示任务预览

- **WHEN** 首页任务卡展示一张或多张候选缩略图
- **THEN** 缩略图不得叠加空心选择圆
- **AND** 点击行为必须继续由整张任务卡承载

#### Scenario: 复核页展示候选

- **WHEN** 用户进入支持逐张选择的复核分组
- **THEN** 普通候选必须显示实际待删除选择状态
- **AND** 点击候选必须能够切换选择

#### Scenario: 复核页展示推荐保留候选

- **WHEN** 复核页展示推荐保留候选
- **THEN** 推荐徽标必须与待删除选择圆使用不同图标和状态来源
- **AND** 推荐候选必须默认显示为未选择删除
- **AND** 用户必须能够逐张选择或取消该候选
- **AND** VoiceOver 必须同时表达推荐状态和实际删除选择状态

### Requirement: 复核分组批量选择必须提供双态反馈

复核页 MUST 根据当前分组普通可清理候选的实际选择状态显示批量操作。批量全选 MUST 始终排除推荐保留候选，批量操作 MUST 只影响当前分组，并且点击结果 MUST 立即反映在候选选择指示器和加入复核箱数量上。用户逐张主动选中的推荐保留候选 MUST 能够通过逐张点击或“取消全选”清除。

#### Scenario: 当前分组尚未全选

- **WHEN** 当前分组至少有一个普通可清理候选未被选中
- **THEN** 批量按钮必须显示“全选本组可清理项”
- **AND** 点击后必须选择当前分组全部普通可清理候选
- **AND** 批量全选不得新增推荐保留候选的选择
- **AND** 已由用户逐张选择的推荐保留候选必须保持原选择状态

#### Scenario: 当前分组已经全选

- **WHEN** 当前分组全部普通可清理候选已经选中
- **THEN** 批量按钮必须显示“取消全选”
- **AND** 点击后必须取消当前分组全部候选的选择，包括手动选中的推荐保留候选
- **AND** 加入复核箱按钮必须同步显示零选择状态

#### Scenario: 自动化验证双态结果

- **WHEN** 自动化在禁用真实 Photos 删除的确定性分组中逐张选择并取消推荐项，再执行取消全选和重新全选
- **THEN** 自动化必须断言推荐徽标保持可见且删除选择、批量按钮文案和操作数量发生对应变化
- **AND** 必须使用 `keepAlways` 保留推荐项已选、推荐项取消和批量选择结果的语义命名截图
