# 第三轮设计

## Context

PrivacySafetyView 以“隐私与安全”为标题，在实际设置项前堆叠承诺；ConfirmedKeepsView 已有网格、逐项取消和全量重置。引导、空态与设置重复安全话术。见 [总方案](../../../docs/13-interaction-redesign-plan.md) 和模拟器基线。

## Goals / Non-Goals

目标是让现有能力可找到、空态可理解，不增加业务功能。保留本地模型控制器和安全开关行为；不把“整理管理”标题误实现为新的规则/自动清理设置。

## Decisions

### 设置分组

使用原生分组列表和既有主题：整理管理只有已确认保留及数量；帮助与隐私包含已有三条详情路由；进阶包含已有本地模型实验和当前状态；版本位于页尾。必要承诺集中在隐私详情，首页只保留简短本地说明，不重复大卡片。模型详情本轮仅做基线补测与入口回归，发现缺陷另立项。

### 保留管理

ConfirmedKeepStore 继续持有资产 ID；视图只保存编辑态与所选 ID，列表变化时清理已失效的选择。默认浏览可点图只读预览；编辑态显示角标、“全选/取消全选”及“取消所选保留（N）”。不显示逐格大按钮或常驻全量操作。

逐项/部分取消给明确反馈和该次操作撤销；全量取消先确认，提示“不会删除照片，后续扫描可能再次出现”。撤销只恢复这次移除的保护记录，并重新执行已有保护协调，不恢复陈旧删除选择。操作期间权限失效不能解释为已删照片；不可访问记录显示占位与状态，仍可移除其保护记录。

### 引导、权限与空态

沿用当前权限所有者与授权结果处理。说明 → 用户点击 → 系统弹窗的顺序不可改变；点击暂不进入无权限首页，不再立即弹第二次说明。Limited 是可继续状态，拒绝/受限提供适当恢复说明，不循环调用权限请求。

空态根据真实数据条件派生，按权限不可用、未完成扫描、已完成且无候选、本轮处理完区分；权限问题优先于“干净相册”结论。保留管理空态帮助文字使用第一轮的“打开照片预览，确认保留”，避免已移除的更多按钮指引。

### 共用约束和规格依赖

不创建新的保护数据库，也不修改 Debug 真实删除授权持久化。取消保留的局部反馈、媒体读取及模型动作超过 300ms 时引用全局 `user-action-contract`，实现前获取技能。

add-confirmed-keeps 的“逐项取消和全部重置”能力保留，只改变到编辑态；跨启动、本地 ID 存储和保护一致性要求不变。若上游推荐保留场景尚未按 disable-recommended-keeps 修订，归档前一并协调，不能让设置改版恢复推荐。首页空态复用第二轮 scan-entry 权限/扫描状态语义，不另建冲突的扫描入口。

## Risks / Trade-offs

2026-11-05 实施细化：设置继续使用原生分组 List；分组标题置于组内语义标题行，版本与隐私短说明置于普通内容行，避免系统 Section header/footer 的字号约束。标题保留无障碍 header 特征，所有说明使用可伸缩语义字体，状态值采用明确对比度颜色；这不增加任何业务入口。

- 隐私说明不再常驻大面积展示 → 首次权限前仍完整说明，设置详情随时可读，删除前仍有影响说明。
- 编辑态增加一次点击 → 防止日常浏览误取消保护；全量操作仍确认，重要动作有反馈。
- 未覆盖的详情页可能有类似问题 → 本轮先补截图审查，不在没有证据时宣称缺陷或自动扩写功能。

## Migration Plan

先设置路由重排，再保留编辑态及存储回归，最后引导/空态和可访问性检查。无数据迁移；可单独回退视觉提交，保留状态数据与安全规则不能被重置。第二轮未交付时不要提前使用新的首页空态路由。
