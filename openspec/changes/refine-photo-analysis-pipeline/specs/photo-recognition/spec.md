## ADDED Requirements

### Requirement: 视觉输入必须保留完整构图与方向

扫描器 MUST 在粗筛和候选复核中使用保持宽高比的本地图像输入，并在生成 Feature Print、pHash、亮度、饱和度、清晰度和图片质量前规范化方向。扫描器 MUST NOT 为适配正方形目标框裁切或拉伸照片内容，分析填充区域 MUST NOT 进入亮度、饱和度或清晰度统计。

#### Scenario: 分析横图、竖图和全景图

- **WHEN** 可访问照片的宽高比不是正方形
- **THEN** 粗筛和候选复核必须保留完整构图和原始宽高比
- **AND** 画面边缘内容不得因目标框而被裁掉
- **AND** 清晰度与质量指标不得统计目标框填充区域

#### Scenario: 分析带方向元数据的照片

- **WHEN** 照片依赖方向元数据才能正确显示
- **THEN** 扫描器必须在生成视觉证据前应用正确方向
- **AND** 同一画面的等价方向表示必须产生可稳定比较的视觉证据

#### Scenario: 回退比较不同宽高比照片

- **WHEN** Vision Feature Print 不可比较且扫描器回退到 pHash
- **AND** 两张照片的宽高比差异超过配置容差
- **THEN** 扫描器不得仅根据正方形填充或归一化结果把它们判为相似

### Requirement: 候选视觉发现必须经过有界二阶段分析

扫描器 MUST 先在视觉分类上限内使用长边不超过 `224px` 的本地图片执行粗筛，再只对粗筛命中的候选使用约 `512px` 的本地图片复核。相似组复核 MUST 覆盖组内全部成员，并在复核结束后重新计算相似关系、质量风险和推荐保留排序。最终结果 MUST 在复核或保守降级完成后一次性发布。

#### Scenario: 粗筛没有发现候选

- **WHEN** 一张照片未进入粗筛相似组且未命中模糊、误拍或边界候选策略
- **THEN** 扫描器不得为该照片请求 `512px` 复核图片

#### Scenario: 粗筛发现相似组

- **WHEN** 粗筛形成至少两张照片的相似组
- **THEN** 扫描器必须复核该组全部成员，包括暂定推荐保留项
- **AND** 最终分类必须使用复核后的 Feature Print、总体质量和可用的人脸拍摄质量
- **AND** 扫描器可以根据复核证据拆分或移除错误的粗筛相似关系

#### Scenario: 粗筛发现疑似模糊或误拍

- **WHEN** 粗筛将单张照片标记为疑似模糊、疑似误拍或配置的边界候选
- **THEN** 扫描器必须在本地资源可用时使用复核图片重新计算对应风险
- **AND** 只有复核后仍满足最终策略的照片才能进入最终模糊或误拍候选

#### Scenario: 候选复核部分不可用

- **WHEN** 粗筛已产生候选但 Photos 无法在禁止网络访问时提供其复核图片
- **THEN** 扫描器可以保留粗筛候选供用户检查
- **AND** 该候选必须标记为未完成复核或低置信度
- **AND** 该候选默认不得被选中删除，也不得被标记为精确重复
- **AND** 扫描必须继续处理其他候选

#### Scenario: 使用不同分辨率的质量阈值

- **WHEN** 扫描器分别计算粗筛和复核清晰度或质量风险
- **THEN** 两个阶段必须使用显式分阶段或尺度归一化的判定策略
- **AND** 扫描器不得未经标定直接复用与旧正方形采样绑定的固定阈值

#### Scenario: 最终分组完成前取消扫描

- **WHEN** 用户在粗筛或候选复核阶段取消扫描
- **THEN** 扫描器必须停止后续分析并丢弃本轮未完成的阶段证据
- **AND** App 不得发布部分完成或仍会变化的复核任务

### Requirement: 精确重复必须使用本地底层资源确认

扫描器 MUST 只在已经命中视觉相似的有界候选组内确认字节级精确重复。精确重复 MUST 由可比较的本地底层资源摘要一致确认，MUST NOT 只使用缩略图、Feature Print、pHash、文件名、尺寸或创建时间确认。底层资源读取 MUST 禁止网络访问，并且资源数据 MUST NOT 上传或持久化为临时副本。

#### Scenario: 普通照片底层资源完全一致

- **WHEN** 两张视觉相似照片具有相同类型的本地主图片资源
- **AND** 流式计算得到的完整资源 SHA-256 摘要一致
- **THEN** 扫描器可以将它们标记为字节级精确重复复核候选
- **AND** 候选仍然不得绕过人工复核、复核箱和二次删除确认

#### Scenario: 画面相似但资源字节不同

- **WHEN** 两张照片的 Feature Print 或高分辨率画面高度相似
- **AND** 底层资源摘要不同或资源类型不可直接比较
- **THEN** 扫描器不得将它们标记为字节级精确重复
- **AND** 扫描器可以继续将它们作为视觉相似候选展示

#### Scenario: Live Photo 精确重复确认

- **WHEN** 待确认资产是 Live Photo
- **THEN** 扫描器必须同时确认主图片和配对视频资源摘要
- **AND** 任一必要资源缺失、不可比较或摘要不同时不得标记为字节级精确重复

#### Scenario: 底层资源只存在于 iCloud

- **WHEN** 精确重复确认所需的底层资源无法在本机读取
- **THEN** 扫描器必须跳过该资源的精确重复确认
- **AND** 扫描器不得下载 iCloud 资源
- **AND** 已有视觉相似候选可以保留，但不得升级为精确重复

## MODIFIED Requirements

### Requirement: 相似照片识别使用有边界的本地视觉信号

扫描器 MUST 在有边界的近期照片分类上限和较短创建时间窗口内，本地粗筛相似照片，并只对粗筛相似组执行候选复核。最终相似分组和推荐保留 MUST 使用复核后的系统图片质量、Feature Print 与可用的人脸拍摄质量。当两张复核照片都具备可比较的 Vision Feature Print 时，扫描器 MUST 优先使用 Feature Print distance，而不是 pHash distance。当 Feature Print 不可用或不可比较时，扫描器 MAY 回退到保持完整构图且宽高比可比较的 pHash distance。

#### Scenario: Vision Feature Print 可用

- **WHEN** 两张非截图照片落在相似时间窗口内
- **AND** 粗筛将它们纳入同一候选子图
- **AND** 两张照片都有可比较的复核 Vision Feature Print
- **AND** 它们的 Feature Print distance 在复核阈值内
- **THEN** 扫描器将它们分组为相似照片复核组
- **AND** 推荐一张保留项，但不得自动删除其他照片

#### Scenario: Vision Feature Print 距离较远

- **WHEN** 两张复核照片有可比较的 Vision Feature Print
- **AND** 它们的 Feature Print distance 超出复核阈值
- **THEN** 扫描器不得再通过 pHash 兜底把它们保留在同一相似关系中

#### Scenario: Vision Feature Print 不可用

- **WHEN** 一张或两张复核照片缺少可比较的 Vision Feature Print
- **AND** 两张照片宽高比可比较
- **AND** pHash distance 在复核阈值内
- **AND** 两张照片落在相似时间窗口内
- **THEN** 扫描器可以将它们分组为相似照片复核候选

#### Scenario: 照片超出时间窗口

- **WHEN** 照片视觉信号相似但超出相似时间窗口
- **THEN** 扫描器不得将它们分组为相似照片

#### Scenario: 相似组包含可比较的人脸照片

- **WHEN** 相似组成员具有复核后的 Vision 人脸拍摄质量结果
- **THEN** 推荐保留排序必须以复核后的总体图片质量为主、人脸拍摄质量为辅
- **AND** 推荐保留项不得自动加入删除选择

#### Scenario: 人脸质量不可用

- **WHEN** 相似组成员没有可用的人脸拍摄质量
- **THEN** 推荐保留排序必须继续使用复核后的总体图片质量

#### Scenario: 复核拆分粗筛相似组

- **WHEN** 粗筛组内部分成员的复核 Feature Print 超出阈值
- **THEN** 最终分类必须移除不成立的相似关系或拆分为多个组
- **AND** 最终稳定分组 ID 必须由复核后的成员集合生成

### Requirement: 质量检测必须保守

扫描器 MUST 把系统图片质量模型、模糊照片和疑似误拍检测作为低置信度复核辅助，并保留可解释的本地图像信号。粗筛命中的模糊、误拍和边界候选 MUST 在本地资源可用时使用约 `512px` 的完整构图重新计算最终风险；未经复核或证据不足的视觉候选默认不得被选中删除。

#### Scenario: 照片质量可能较差

- **WHEN** 复核后的本地质量信号显示模糊、曝光极端或画面信息较低
- **THEN** 扫描器可以创建模糊或误拍复核候选
- **AND** 该候选默认不得被选中删除

#### Scenario: 系统模型给出极低图片质量分

- **WHEN** 复核阶段 Vision 图片美学评分极低
- **AND** 图片没有被标记为 utility
- **THEN** 扫描器可以将模型低分作为疑似误拍的辅助信号
- **AND** 该候选默认不得被选中删除

#### Scenario: 系统模型标记 utility 图片

- **WHEN** Vision 将图片标记为 utility
- **THEN** 扫描器不得只根据该标记把图片归为疑似误拍或可删除候选

#### Scenario: 系统模型请求失败

- **WHEN** 粗筛或复核阶段 Vision 图片美学评分失败或没有结果
- **THEN** 扫描器必须回退到对应阶段的本地启发式质量信号
- **AND** 单张图片失败不得中断其他资源扫描

#### Scenario: 粗筛风险未通过复核

- **WHEN** 粗筛将照片标记为疑似模糊或误拍
- **AND** 复核证据不再满足最终风险阈值
- **THEN** 扫描器不得把该粗筛风险发布为最终模糊或误拍候选

### Requirement: 识别保持本地且有边界

视觉识别 MUST 本地运行，不得请求网络回源的 iCloud 图片或底层资源下载。粗筛、候选复核、Vision Feature Print、质量评估和精确重复确认 MUST 只在视觉分类上限及其派生候选集合内运行。扫描器 MUST 优先使用本地快速图片资源；当快速图片资源不可用但完整本地图片仍可读取时，扫描器 MUST 使用仍然禁止网络访问的高质量本地图片请求重试同一阶段。

#### Scenario: 快速图片资源可用

- **WHEN** Photos 能够从本地快速图片资源提供当前阶段所需图片
- **THEN** 扫描器使用该图片生成当前阶段视觉证据
- **AND** 扫描器不得再为同一照片和同一阶段执行高质量回退请求

#### Scenario: 快速图片资源缺失但完整本地图片可用

- **WHEN** Photos 的快速图片请求返回空结果或资源缺失错误
- **AND** 完整本地图片仍然可用
- **THEN** 扫描器必须使用禁止网络访问的高质量本地图片请求重试同一粗筛或复核阶段
- **AND** 成功读取的图片必须继续进入该阶段的 Feature Print 和质量评估

#### Scenario: 粗筛本地图像数据不可用

- **WHEN** Photos 无法在不允许网络访问的情况下通过快速和高质量请求提供粗筛图片
- **THEN** 跳过该资源的视觉粗筛
- **AND** 扫描继续处理其他可用资源

#### Scenario: 复核本地图像数据不可用

- **WHEN** 粗筛图片可用但 Photos 无法在不允许网络访问的情况下提供复核图片
- **THEN** 扫描器必须执行低置信度降级而不是请求网络
- **AND** 扫描继续处理其他复核候选

#### Scenario: 原始资源摘要不可用

- **WHEN** Photos 无法在禁止网络访问时提供精确重复确认所需的底层资源
- **THEN** 扫描器必须跳过该资源的精确重复确认
- **AND** 该失败不得中断视觉相似、质量评估或其他资源扫描

#### Scenario: 候选集合小于粗筛集合

- **WHEN** 粗筛完成并生成有限候选集合
- **THEN** `512px` 复核和原始资源摘要必须只处理该候选集合或其中更小的疑似重复子集
- **AND** 扫描器不得把所有已粗筛照片升级为高清或原始资源读取
