## Purpose

定义以复核任务为核心的首页结果层级、可按需查看的扫描诊断信息和进度完成中断呈现，确保范围与覆盖局限可理解、重新扫描可发现，并在扫描失败取消及并发用户决定时保留可信的既有会话。

## ADDED Requirements

### Requirement: 首页必须优先展示当前可复核结果

已有结果时首页 MUST 按本次范围/时间、覆盖局限、剩余候选摘要和任务组织；详细缓存、耗时和报告导出 MUST 放在扫描详情，不得用常驻大号重扫动作挤压任务。重新扫描 MUST 以可见、可访问的文字入口保留，任务 MUST 继续按唯一 ID 打开。

#### Scenario: 有任务且访问有限
- **WHEN** Limited Access 下扫描产生候选
- **THEN** 首页同时显示本次范围、访问有限/不可读取摘要、任务与重扫入口，不声称覆盖完整图库

#### Scenario: 查看扫描详情和导出
- **WHEN** 用户进入扫描详情
- **THEN** 可以查看真实覆盖、缓存和耗时，并从该页发起报告导出；分享前提示报告实际包含的信息和分享风险

### Requirement: 运行中与完成中断必须使用对应的最小操作集合

扫描中 MUST 使用一个固定位置进度区表达真实阶段；未知总量时 MUST 不伪造百分比，不得重复放置无意义的“扫描中”禁用按钮。首页 MUST 只有一个进入当前扫描的状态入口，不允许重复启动。完成 MUST 提供结果摘要与查看结果；中断 MUST 提供原因、同范围重试和返回路径。

#### Scenario: 浏览期间扫描结束
- **WHEN** 用户已离开进度页并在其他页面操作时扫描完成
- **THEN** 更新扫描状态但不强制跳转，用户可主动查看新结果

#### Scenario: 进度页扫描结束
- **WHEN** 用户停留进度页直到完成
- **THEN** 原地显示完成数量、覆盖局限和“查看结果”，不继续以过程计数为主要内容

#### Scenario: 请求取消
- **WHEN** 用户取消扫描
- **THEN** 局部显示停止中并防重复，终止后提供“重试此范围”和返回旧结果或首页，不发布半成品

### Requirement: 新结果必须事务式替换旧会话

新扫描运行期间 MUST 保留旧结果、复核箱、保留决定及旧删除摘要，旧结果界面 MUST 标明归属。失败或取消 MUST 不丢弃旧会话；成功提交 MUST 一次发布新结果并重置旧删除摘要，提交前 MUST 协调最新权限、保护记录和成功删除事实。

#### Scenario: 删除后重扫失败
- **WHEN** 旧结果含删除摘要，新扫描失败或取消
- **THEN** 旧候选和摘要仍可查看，重试可用，不错误显示新扫描已完成

#### Scenario: 扫描期间用户确认保留或删除
- **WHEN** 用户在新扫描运行期间处理旧结果且新扫描随后成功
- **THEN** 新结果不得复活成功删除资源，不得把最新已确认保留项纳入可清理统计；上一轮删除摘要不带入新周期

### Requirement: 首页扫描优化必须保留可访问的状态证据

范围、局限、完成与恢复状态 MUST 支持最大 Dynamic Type、VoiceOver 与稳定自动化标识。测试 MUST 禁用真实删除并保留首页有任务、范围草稿取消、运行中继续浏览、完成、中断和大字号截图。

#### Scenario: 复查扫描范围与结果
- **WHEN** 自动化提交一个范围并完成确定性扫描
- **THEN** 设置、进度和结果的范围一致，取消下一次草稿不改变当前结果，关键截图以 keepAlways 保留
