## ADDED Requirements

### Requirement: 公开支持与隐私页面

TrueKeep MUST 在当前 GitHub 仓库的 Pages 站点提供无需登录即可访问的隐私政策和支持页面。页面 SHALL 提供中英双语说明、有效的支持邮箱，以及相互可导航的链接。

#### Scenario: 用户访问支持页面

- **当** 用户打开公开的支持 URL
- **则** 页面显示联系邮箱 `qmkhaust@gmail.com`、常见问题和隐私政策入口
- **并且** 不要求用户登录网站或提供照片

#### Scenario: 用户了解数据处理

- **当** 用户打开隐私政策
- **则** 页面说明照片与视频本地分析、确认保留资源 ID 的持久化与清除方式、照片权限、二次删除确认和 iCloud 风险
- **并且** 区分 App 处理行为与网站托管、主动支持邮件涉及的数据处理

### Requirement: 限定网站发布范围

网站发布 MUST 仅部署经过校验的网页和样式白名单文件，且 SHALL 不包含 App 源码、测试产物或工程文档。

#### Scenario: 网站源文件更新

- **当** `dev` 分支的网站源文件更新
- **则** 工作流先验证本地链接、必备页面、邮箱与占位符，再上传限定的 Pages 产物

#### Scenario: 发布完成

- **当** GitHub Pages 报告部署成功
- **则** 验证公开首页、隐私政策和支持页返回正常响应，保留桌面及移动端命名截图和部署记录
