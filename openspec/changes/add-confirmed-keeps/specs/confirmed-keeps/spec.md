## ADDED Requirements

### Requirement: 用户必须能够明确确认照片保留

复核页 MUST 为每张未保护候选提供“确认保留，不再提醒”操作。用户确认后，App MUST 立即把该资源标记为用户确认保留，取消其删除选择并将其移出复核箱。用户确认保留 MUST 与算法生成的推荐保留使用不同状态和文案。

#### Scenario: 用户确认普通候选保留

- **WHEN** 用户对一个未保护候选执行“确认保留，不再提醒”
- **THEN** 候选必须显示“已确认保留”状态
- **AND** 候选不得继续计入当前删除选择、复核箱、待复核数量或预计可释放空间
- **AND** App 必须提供即时撤销

#### Scenario: 用户确认算法推荐项保留

- **WHEN** 候选同时具有算法“推荐保留”标记
- **AND** 用户确认该候选保留
- **THEN** App 必须记录独立的用户确认状态
- **AND** 界面和 VoiceOver 必须能够区分“推荐保留”和“已确认保留”

### Requirement: 已确认保留必须跨启动和跨扫描生效

App MUST 仅在本机持久化已确认保留的 Photos 资源 ID，并在后续启动和扫描中读取。App MUST NOT 为该能力保存照片、缩略图、视觉特征或上传用户偏好。

#### Scenario: 用户重新启动后再次扫描

- **WHEN** 用户确认资源保留后退出并重新启动 App
- **AND** 后续扫描仍能访问同一 Photos 资源
- **THEN** 该资源不得再次作为普通可删除候选出现
- **AND** 保护状态必须继续阻止逐张和批量删除选择

#### Scenario: 保护资源已不可访问

- **WHEN** 已保存的资源 ID 因删除或 Photos 权限变化而不可访问
- **THEN** App 必须继续完成其余可访问资源的扫描
- **AND** 孤立保护记录不得导致扫描失败或扩大 Photos 权限范围

### Requirement: 相似扫描必须保留保护项的比较价值

扫描器 MUST 允许已确认保留照片继续参与本地相似关系判断。相似组包含新的未保护候选时，App MAY 将保护照片显示为只读比较参考，但 MUST NOT 把它计入待复核数量、预计可释放空间、默认选择或批量选择。非相似类别 MUST NOT 再次展示保护资源。

#### Scenario: 保护照片与新照片相似

- **WHEN** 一个已确认保留照片与一个或多个新照片满足相似分组条件
- **THEN** 新照片必须能够继续生成相似复核任务
- **AND** 保护照片可以显示为“已确认保留”的比较参考
- **AND** 保护照片不得被选择删除

#### Scenario: 分组只剩保护或推荐保留资源

- **WHEN** 一个分组没有未保护的普通可操作候选
- **THEN** App 不得为该分组生成首页待复核任务

#### Scenario: 非相似保护资源再次命中规则

- **WHEN** 已确认保留资源再次命中截图、大视频、误拍或模糊规则
- **THEN** App 不得在对应复核任务中再次展示该资源

### Requirement: 用户必须能够管理和撤销保护记录

设置页 MUST 展示已确认保留数量，并为可见记录提供逐项取消和全部重置。取消保护 MUST 更新本地记录和当前共享状态，并明确说明资源可能在后续扫描中再次出现。

#### Scenario: 用户逐项取消保护

- **WHEN** 用户在设置页取消一张照片的确认保留
- **THEN** 该资源 ID 必须从本地保护记录移除
- **AND** 如果当前扫描状态仍包含该资源，保护标记必须立即取消
- **AND** App 必须说明它可能在下次扫描再次出现

#### Scenario: 用户全部重置

- **WHEN** 用户确认全部取消保留
- **THEN** App 必须清空本地保护记录
- **AND** 当前共享状态中仍存在的保护标记必须同步清除
- **AND** App 不得修改或删除任何 Photos 资源

### Requirement: 自动化必须隔离保护记录并保留截图

UI 自动化 MUST 使用样例资源和显式重置配置隔离保护记录，MUST 继续禁用真实 Photos 删除，并 MUST 使用 `keepAlways` 保留确认成功、跨启动生效和设置管理的语义命名截图。

#### Scenario: 自动化验证跨启动保护

- **WHEN** 自动化确认一个样例候选保留并重新启动 App
- **THEN** 保护状态和待复核数量必须保持一致
- **AND** 测试不得调用 Photos 删除 API
- **AND** 必须保留跨启动保护结果截图
