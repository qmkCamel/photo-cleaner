## MODIFIED Requirements

### Requirement: 首页预览不得伪装成可选择控件

首页任务中的缩略图 MUST 只作为任务内容预览，不得展示不可交互的空心选择圆、选中状态或推荐保留徽标。逐张选择指示器 MUST 只出现在支持候选选择的复核界面；推荐保留能力关闭时，复核界面也 MUST NOT 展示推荐保留图标、文案或无障碍语义。

#### Scenario: 首页展示任务预览

- **WHEN** 首页任务卡展示一张或多张候选缩略图
- **THEN** 缩略图不得叠加空心选择圆或推荐保留徽标
- **AND** 点击行为必须继续由整张任务卡承载

#### Scenario: 复核页展示候选

- **WHEN** 用户进入支持逐张选择的复核分组
- **THEN** 全部未确认保留候选必须显示实际删除选择状态
- **AND** 候选不得显示推荐保留徽标或播报推荐保留语义
- **AND** 用户必须能够逐张切换未确认保留候选

### Requirement: 复核分组批量选择必须提供双态反馈

复核页 MUST 根据当前分组全部未确认保留候选的实际选择状态显示批量操作。推荐保留能力关闭时，不得再从批量选择中排除内部质量比较排名靠前的候选；用户确认保留候选 MUST 继续排除。批量操作 MUST 只影响当前分组，并且点击结果 MUST 立即反映在候选选择指示器和加入复核箱数量上。

#### Scenario: 当前分组尚未全选

- **WHEN** 当前分组至少有一个未确认保留候选未被选中
- **THEN** 批量按钮必须显示“全选本组可清理项”
- **AND** 点击后必须选择当前分组全部未确认保留候选
- **AND** 内部质量比较结果不得让任何未保护候选被跳过

#### Scenario: 当前分组已经全选

- **WHEN** 当前分组全部未确认保留候选已经选中
- **THEN** 批量按钮必须显示“取消全选”
- **AND** 点击后必须取消当前分组全部候选的选择
- **AND** 加入复核箱按钮必须同步显示零选择状态

#### Scenario: 自动化验证双态结果

- **WHEN** 自动化在禁用真实 Photos 删除的确定性分组中执行全选和取消全选
- **THEN** 自动化必须断言批量按钮文案、候选选择和加入复核箱数量发生对应变化
- **AND** 必须使用 `keepAlways` 保留推荐已屏蔽和用户手动选择结果的语义命名截图

## ADDED Requirements

### Requirement: 推荐关闭时相似组必须保持保守默认

推荐保留能力关闭时，相似照片任务和复核组 MUST 使用用户逐张判断流程。App MUST 默认保持相似组零选择，MUST NOT 展示或播报推荐结果，并且 MUST 在用户明确选择前禁用“加入复核箱”和“直接删除”。用户确认保留 MUST 继续作为独立保护状态生效。

#### Scenario: 用户进入相似照片组

- **WHEN** 用户打开推荐保留能力关闭的相似照片复核组
- **THEN** 组内全部未确认保留候选必须默认保持未选择删除
- **AND** 页面、首页任务和 VoiceOver 不得出现推荐保留文案或标记
- **AND** “加入复核箱”和“直接删除”必须不可用

#### Scenario: 用户明确选择一张相似照片

- **WHEN** 用户逐张点击一张未确认保留的相似照片
- **THEN** App 必须只把该候选加入当前删除选择
- **AND** 两个删除入口必须同步显示一项选择
- **AND** 用户再次点击时必须能够取消该选择

#### Scenario: 相似组包含用户确认保留项

- **WHEN** 相似组中的照片已被用户确认保留
- **THEN** 该照片必须继续显示用户确认保留状态
- **AND** 该照片不得进入逐张或批量删除选择
- **AND** 其他未确认保留照片不得因为内部质量排名而被隐藏或保护
