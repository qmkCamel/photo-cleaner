## ADDED Requirements

### Requirement: 已授权用户必须能从首页开始扫描

当用户已经完成引导且 Photos 授权允许扫描时，首页 MUST 提供可见且可访问的扫描入口，不得要求用户重新触发系统授权流程。

#### Scenario: 已授权用户冷启动但没有内存扫描结果

- **当** 用户已经完成引导并具有 Full Access 或 Limited Access
- **并且** 当前运行周期尚未完成扫描
- **则** App 必须直接进入首页
- **并且** 首页必须显示“扫描相册”入口
- **并且** 空态不得声称已经扫描但未发现候选

#### Scenario: 扫描完成但没有候选

- **当** 当前运行周期已经完成扫描且没有生成复核候选
- **则** 首页必须提供“重新扫描”入口
- **并且** 点击后必须进入现有扫描进度页

#### Scenario: 扫描完成并生成复核任务

- **当** 当前运行周期已经完成扫描且首页存在复核任务
- **则** 结果页必须提供可见、可点击的“重新扫描”入口
- **并且** 入口必须位于系统 Tab Bar 上方，不得遮挡复核任务
- **并且** 点击后必须进入现有扫描进度页

#### Scenario: 用户尚未授权照片访问

- **当** Photos 授权状态为 notDetermined
- **则** 首页必须显示照片访问说明和“开启访问”入口
- **并且** 不得同时显示直接扫描入口

### Requirement: 首页扫描操作必须复用现有进度和恢复路径

首页发起的扫描 MUST 使用现有本地扫描、取消、完成和中断状态，不得在首页无反馈地执行长耗时扫描。

#### Scenario: 用户从首页开始扫描

- **当** 用户点击“扫描相册”或“重新扫描”
- **则** App 必须立即进入扫描进度页
- **并且** 用户必须能够取消扫描
- **并且** 扫描不得自动删除、移动或上传任何照片或视频
