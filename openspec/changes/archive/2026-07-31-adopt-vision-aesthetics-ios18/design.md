# 设计：Vision 图片质量评分与保守融合

## 信号结构

每张进入有界视觉扫描的本地缩略图继续生成：

- Vision feature print，用于相似分组。
- 亮度、饱和度、边缘清晰度和感知 hash，用于解释和确定性兜底。
- Vision 图片美学 `overallScore` 与 `isUtility`。
- 可用时的人脸拍摄质量均值。

Vision 的 `overallScore` 从 `[-1, 1]` 归一化到 `[0, 1]`，作为 `overallQuality`。相似组推荐保留分以总体质量为主；有人脸质量时使用 `80%` 总体质量与 `20%` 人脸拍摄质量，避免人脸信号覆盖整体照片质量。

## 疑似误拍融合

启发式误拍风险继续由极端曝光和低画面信息信号生成。Vision 只在以下条件同时满足时提供额外误拍风险：

- `isUtility == false`；
- `overallScore < 0`。

模型风险使用 `max(0, -overallScore)`，再与启发式风险取最大值。现有分类阈值 `0.85` 保持不变，因此只有非常低的 Vision 分数才会单独触发疑似误拍候选。

`isUtility == true` 不得触发误拍候选。票据、文档和其他工具型图片可能有明确用途，不能因为“不一定值得分享”就推断为可清理。

## 模糊与解释

Vision 当前只公开总体分，不公开单独的模糊、曝光或误拍原因。`blurRisk` 继续使用边缘清晰度规则；候选文案继续描述可核验的亮度、色彩或清晰度信号，不把黑盒分数写成确定性结论。

## 失败路径

如果 Vision 请求抛错、没有返回结果或人脸质量不可用：

- 总体质量回退到现有启发式评分；
- 模糊和误拍风险继续由现有规则生成；
- feature print 不可用时继续回退 pHash；
- 单张图片失败不得中断整个图库扫描。
