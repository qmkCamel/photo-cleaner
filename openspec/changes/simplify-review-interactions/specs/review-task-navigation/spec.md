## MODIFIED Requirements

### Requirement: 首页预览不得伪装成可选择控件

首页任务中的缩略图 MUST 只作为任务内容预览，不得展示不可交互的空心选择圆、选中状态或推荐保留徽标。逐张选择指示器 MUST 只出现在支持候选选择的复核界面；推荐保留能力保持关闭。复核页 MUST 区分图片预览操作与独立角标选择操作，用户确认保留项只能预览不能选择。

#### Scenario: 首页展示任务预览
- **WHEN** 首页任务卡展示一张或多张候选缩略图
- **THEN** 缩略图不得叠加选择圆或推荐保留徽标，点击行为由整张任务卡承载

#### Scenario: 复核页展示候选
- **WHEN** 用户进入支持逐张选择的复核分组
- **THEN** 未确认保留候选的角标表达实际选择，点角标只切换该项选择，点图片只打开预览
- **AND** 已确认保留项不得加入选择，页面和 VoiceOver 不得出现推荐保留语义

### Requirement: 复核分组批量选择必须提供双态反馈

复核页 MUST 按当前分组未确认保留候选的实际选择状态显示批量操作。内部质量排名 MUST NOT 排除任何未保护候选，已确认保留项 MUST 排除。批量操作 MUST 只影响当前分组并立即更新角标、数量和所选大小；没有可选择候选时 MUST 隐藏批量操作。

#### Scenario: 当前分组尚未全选
- **WHEN** 当前组至少有一个可选择候选未选中，包括部分已选状态
- **THEN** 操作显示“全选可清理项”，点击选择当前组全部未确认保留候选
- **AND** 已确认保留保持未选，内部排名不影响选择

#### Scenario: 当前分组已经全选
- **WHEN** 当前组所有可选择候选均已选中且至少有一项
- **THEN** 操作显示“取消全选”，点击取消本组全部选择，加入复核箱同步变为零选择状态

#### Scenario: 自动化验证双态结果
- **WHEN** 非破坏性确定性测试执行全选和取消全选
- **THEN** 断言文案、角标、操作数量与所选大小一致，并以 keepAlways 保留双态截图
- **AND** 确认保留项不会选中，其他分组不受影响
