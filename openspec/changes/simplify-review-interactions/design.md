# 第一轮设计

## Context

依据 [总方案与截图基线](../../../docs/13-interaction-redesign-plan.md)。当前 ReviewGroupView 中照片按钮负责选择、每格另有预览和更多按钮，底部集中多行操作；MediaReviewView 确认保留后由父级关闭；ReviewBinView 内嵌删除确认表单。改动重点是交互映射，不是识别结果。

## Goals / Non-Goals

目标：内容优先、操作可预测、保护与选择不混淆，删除结果仍完整可恢复。非目标：改变扫描算法、默认推荐、真实删除许可、存储版本或自动处理策略。私有照片参考稿不复制为仓库公共素材。

## Decisions

### 页面结构与动作映射

普通手机采用总方案的双列网格和稳定动作区；`adapt-iphone-duo` 将列数扩展为按实际可用宽度的 1–4 列，大字号仍单列，矮窗口/辅助功能字号的动作放入同一滚动内容以保证可达，不强制固定在物理底部。图片按钮只预览，角标按钮只选择，二者是兄弟控件，避免嵌套按钮和点击透传；保持资源 ID 驱动定位。每格不再常驻“预览”文字与省略号；确认保留可从预览主工具栏及无障碍自定义动作访问，长按仅为快捷方式，不是唯一入口。

延续现有跨类别上一组/下一组导航，页内组序号按全体复核分组计算，而非拿类别内的 1/1 配跨类别箭头。完成后显示本组完成，不把删除后缩短数组的新索引当作刚完成的组。

批量按钮：有未选可清理项时“全选可清理项”，全部选中时“取消全选”；没有可清理项则隐藏。部分选择不采用稿中可能含混的“取消选择”，保证双态判定唯一。零选择的底部按钮中性禁用；已有默认策略不变，尤其相似/模糊/误拍零默认选择。

“加入复核箱（N）”是主路径；顶部更多提供“删除所选 N 项…”。次级保留操作按未选且未保护集合计算，不把所选删除项一起保护。每次保留记录一次可撤销操作，撤销仅移除该次新增的保护，不恢复先前删除选择或复核箱引用。

### 状态所有权与调用链

继续使用共享复核状态派生 eligibleIDs、selectedEligibleIDs、confirmedKeepIDs，数量与字节都按去重资源计算。estimatedBytes 缺失时显示“部分大小未知”；本组可清理总量和当前所选量必须用不同文案。视图不缓存另一套已删除/已保留事实。

选择/保留 → 现有共享 mutation → ConfirmedKeepStore / ReviewSessionStore → 各页派生状态。删除菜单 → 现有确认状态 → PhotoLibraryDeletionService → 按成功 ID 协调组、箱、首页与预览。不能因入口移动新建删除执行器或在成功回调前移除照片。

MediaReviewView 使用当前资源 ID 而非只依赖索引；确认保留反馈后停留查看器，内容删除或授权失效时显示可退出的稳定状态。保留预览可查看但不提供删除选择；本地资源不可用显示局部重试，不自动下载。加载、重试、删除等超过 300ms 的动作实施前遵守全局 `user-action-contract`，本方案不复制该技能。

### 复核箱与确认表单

移出仅调用现有移除箱记录操作，取消选择和更新数量，不调用 Photos 删除、不新增保护。单行概述与按需展开安全说明替代两套重复提示。30 天仅指记录有效期，测试验证到期不触达删除服务。

确认使用内容适配的 sheet；小屏和大字号可扩为大尺寸并滚动，不能固定高度裁切。保留取消和带数量的 destructive 动作，不把危险操作包装为绿色主按钮；进行中阻止重复提交和不安全关闭，其他不相关导航不被全局锁死。失败项维持选择和可重试上下文。

### 规格依赖和最终优先级

| 上游提案/要求 | 本轮最终行为 | 落地门禁 |
| --- | --- | --- |
| add-direct-review-deletion / 两个同层级动作、整图点击选择 | 主操作加入箱，菜单直接删；角标选择，图片预览 | 上游归档时同步这些入口场景；安全、结果协调场景原样保留 |
| disable-recommended-keeps / 批量文案、逐张点击 | 推荐保持关闭；逐张明确为角标；新短文案 | 本轮 navigation 增量在其后合入，不能由旧增量回写 |
| add-confirmed-keeps / 推荐与用户保留并存场景 | 只展示用户保留，内部排名不等于保护 | 协调旧推荐场景，不重启功能 |
| add-media-review-decisions / 预览决定 | 保留在预览内反馈并停留，其余安全契约保留 | 与本轮共同验证，不重复建存储 |

现有上游提案仍有未验收任务，不能强制标完成归档。实现前先对照最新上游文本；归档前上游若未归档，须把被替代条款显式修订并安排接受顺序，或暂缓本轮归档。禁止留下互相冲突的正式规格。

## Risks / Trade-offs

2026-11-05 实施细化：复核箱的滚动区与底部操作栏使用独立布局区域，滚动内容在自身边界裁切；折叠的删除须知放在缩略图前，避免说明入口落在首屏裁切边缘。文字操作的 44pt 热区放在 Button label 内部，不依赖按钮外层空白；最大字号的选择摘要与全选操作改为纵向布局。

- 图片点击语义改变 → 使用独立可见角标、VoiceOver 提示和 UI 测试，不保留旧整格切换以免双重触发。
- 直接删除可发现性降低 → 顶部有明确更多按钮，菜单项带数量，首次不弹教程打断。
- 双列网格增加长组滚动 → 懒加载，保留当前组滚动位置；不为省空间恢复多个逐项按钮。
- 保留撤销遇到外部变化 → 按资源 ID 与当前权限协调，不恢复已删除资源或覆盖其他用户决定。

## Migration Plan

先改共享组件语义与选择派生，再分组/预览，再复核箱与确认，最后更新各类别测试和可访问性。无数据迁移，不新增兼容分支。出现回归可回退本轮视图提交，但不能回滚删除安全锁、保留记录或既有删除结果协调修复。
