## ADDED Requirements

### Requirement: 重排必须保持用户意图与呈现状态

折叠、展开、旋转或窗口缩放 MUST 保持当前 Tab、稳定任务/资源 ID、选择集合、保留编辑草稿、范围草稿和表单意图。状态 MUST 属于稳定所有者，而非依赖可能重建的列或视图实例；自动产生的布局变化 MUST NOT 作为用户确认、取消或再次进入的依据。

#### Scenario: 范围草稿在展开后取消
- **WHEN** 用户修改范围但未开始扫描，展开后选择取消
- **THEN** 已完成结果范围和持久偏好不变，也不发起扫描或权限请求

#### Scenario: 保留编辑中收起
- **WHEN** 用户选择部分保留记录准备取消保护，然后收起设备
- **THEN** 编辑状态和所选 ID 保留；退出编辑不修改保护数据，明确提交才执行

#### Scenario: 资源在布局变化期间不可用
- **WHEN** 当前资源被外部删除或权限收缩
- **THEN** 呈现真实不可用状态，清除失效操作并保留返回路径，不自动替换为其他资源

### Requirement: 布局变化不得复制或误取消长任务

扫描、报告、媒体加载与模型工作 MUST 遵循全局 user-action-contract 并由稳定所有者持有。纯布局重建 MUST NOT 重复启动任务、丢失结果或被当成用户离页；明确取消、关闭或真实离开按各动作既定生命周期处理。

#### Scenario: 扫描处理中连续展开收起
- **WHEN** 扫描超过 300ms，用户展开、旋转、进入分屏并继续浏览
- **THEN** 扫描请求次数仍为一，阶段和结果一致，后台完成不抢走当前导航
- **AND** 取消可达，只有底层停止后才显示已停止，旧结果保持到新扫描成功提交

#### Scenario: 报告生成失败并重试
- **WHEN** 报告生成中重排，随后首次生成失败
- **THEN** 局部忙碌正确收尾、原请求快照可辨认，用户可重试并得到可分享结果
- **AND** 重排不造成第二次编码或旧结果覆盖新结果

#### Scenario: 本地模型任务跨布局
- **WHEN** 下载、校验或分析中窗口变化
- **THEN** 原控制器和任务继续被观察，取消/失败恢复入口保持可用，不增加执行次数

### Requirement: 删除必须跨布局保持单一提交与准确结果

直接删除和复核箱删除 MUST 使用布局外的单一请求所有者，冻结资源快照并保护重复提交；布局变化 MUST NOT 扩大授权、自动确认、重复请求或丢弃已经提交的结果。

#### Scenario: 未确认删除时切换形态
- **WHEN** 用户打开删除确认后展开或收起
- **THEN** 确认仍对应原资源集合，没有任何 Photos 删除请求
- **AND** 若系统关闭未提交表单，App 明确表明未提交，不把关闭解释为确认

#### Scenario: 确认前资源集合变化
- **WHEN** 确认快照中的资源失效、权限变化或被设为保留
- **THEN** App 重新校验并展示有效数量/变化说明，要求重新确认，不静默使用变化后的集合提交

#### Scenario: 已提交删除时连续重排和再次点击
- **WHEN** 删除服务尚未完成，用户改变窗口并尝试再次提交
- **THEN** 服务只执行一次，当前布局显示真实处理中状态，不呈现虚假取消
- **AND** 服务完成后按成功 ID 同步候选、复核箱、选择和摘要，失败项保持可恢复

#### Scenario: 删除结果未知
- **WHEN** 场景中断导致无法确认删除结果
- **THEN** App 先核对资源状态并提供明确恢复路径，不假报全失败或自动重试已提交集合

### Requirement: 媒体连续性不得扩大本地访问边界

媒体预览跨布局 MUST 保留当前资源 ID、合理缩放锚点和视频播放时间/状态。请求更新 MUST 拒收过时回调，继续禁止为复核自动下载 iCloud 原图。

#### Scenario: 视频播放中展开
- **WHEN** 用户正在播放本地测试视频并展开窗口
- **THEN** 仍显示同一资源，播放位置/播放状态连续，不新建并行播放器或从头自动播放

#### Scenario: 旧图片请求晚于新布局返回
- **WHEN** 布局引起图片请求规格更新而旧请求随后完成
- **THEN** 只有匹配当前资源和请求身份的结果可显示，不串图、不恢复失效资源

### Requirement: Duo 支持声明必须有可追溯验证证据

发布前 MUST 完成 design.md 的 D01–D08 验收矩阵及现有关键流程回归。MUST 区分 fixture、真实本地媒体、模拟器姿态、手动步骤和真机结果；不得用普通手机或矩形预览替代 Duo 原生模拟器验收。

#### Scenario: 自动化验收产生证据
- **WHEN** 执行新的 Duo UI 用例
- **THEN** 显式禁用真实删除，以命名 keepAlways 截图保留关键过程、结果与适用的失败恢复
- **AND** 报告记录实际窗口参数、runtime、构建、用例断言与截图路径

#### Scenario: 验证动态切换无重复副作用
- **WHEN** 验证复核选择和删除确认/处理中跨形态
- **THEN** 至少保留两段连续切换录屏及服务调用计数/状态断言，不能仅凭前后截图宣称连续性

#### Scenario: 工具暂不支持某种姿态控制
- **WHEN** 当前自动化工具没有受支持的折叠控制接口
- **THEN** 使用官方 Device Hub 可重复手动步骤并标注人工验证，不能编造命令或勾选为自动化通过

#### Scenario: 仍有无障碍或最低系统验收失败
- **WHEN** 删除确认文字裁切、最低系统或安全流程仍未验收通过
- **THEN** 保留失败记录与未完成任务，不发布“已完整适配 Duo”或归档结论
