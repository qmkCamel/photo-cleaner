# iPhone Duo 全流程自适应

## Why

iPhone Duo 的外屏、内屏、半折叠和分屏会在一次使用过程中持续改变 App 可用区域。当前 TrueKeep 已有单一共享清理状态和原生 Tab 导航，但网格列数主要按字号决定，部分图片高度、底部留白及操作栏仍按普通直板手机布局；宽屏利用、非对称安全区和布局切换中的操作连续性尚未验收。

需要在现有三轮交互改版基础上完成完整适配，保证“展开更好复核，收起继续操作”，而非仅把界面拉宽。当前删除确认页的文字裁切审查仍未通过，不能把旧问题带入新的支持声明。

## What Changes

- 以当前窗口实际可用空间、size class、Dynamic Type 和系统保留区域决定布局，不通过机型、屏幕英寸或设备方向推断界面。
- 保留首页、复核箱、设置三个原生 Tab；使用系统导航和工具栏适应侧边控件区域，不复制一条自定义竖向 Tab。
- 窄窗口保持列表到详情的导航；足够宽的首页采用任务列表与当前复核组双栏。网格按可用宽度调整，辅助功能大字号优先单列。
- 覆盖引导、权限、扫描设置/进度/结果/报告、各类复核、照片与视频预览、复核箱、删除确认、保留管理、帮助隐私和模型内页。
- 用稳定任务/资源 ID 和布局外的操作所有者保持路由、选择、范围草稿、预览与正在执行的任务；折叠不重扫、不重复删除、不自动改变保留决策。
- 把外屏、内屏、分屏、半折叠、旋转、动态切换以及无障碍验证纳入可复现用例，保存截图和连续切换录屏。
- 明确构建 SDK 与最低运行系统的区别：Duo 发布构建使用 iOS 27.1 或更高 SDK，现有 iOS 18 最低支持不变，新 API 按可用性隔离。

非目标：不发布 iPad/Mac 版，不做两屏同时操作、镜像图库或多人复核，不新增双图比较/跨组批处理，不改识别算法和推荐策略，不新增真实删除授权方式，不自动下载 iCloud 内容，不重做品牌。

安全边界：继续本地处理、Limited 有效、低置信度保守选择、保留项保护及二次删除确认。常规验收显式禁删；真实删除与私有图库测试须另有授权计划。

2026-11-05：方案已获用户要求进入实现。本变更包含 App 代码与模拟器自动化；不安装到真机、不发布，不扩大真实删除授权。

## Capabilities

### New Capabilities

- `adaptive-window-layout`：全页面在动态窗口、安全区域及系统工具栏变化下的布局和可访问性。
- `adaptive-review-continuity`：布局变化期间导航、选择、预览、扫描与危险操作连续性，以及验收证据。

### Modified Capabilities

- `platform-support`：增加 Duo 构建与支持声明门槛，保留既有 iOS 18 最低部署需求。

## Impact

涉及 `AppRootView` 的导航拓扑和长任务所有者、共享布局策略、ReviewGroupView、ReviewBinView、MediaReviewView、CleanupResultsView、ScanProgressView、PrivacySafetyView、引导/权限/模型页面、XcodeGen 配置和 UI 自动化。复用现有 Photos 服务、会话与保护存储，不迁移用户照片或另建数据仓库。

依赖 `simplify-review-interactions`、`prioritize-home-review-results`、`reorganize-settings-and-onboarding` 当前实现；不会把它们未完成的真实媒体、跨设备或无障碍验收标记完成。上游规格协调、分阶段交付及来源见 design.md。
