## MODIFIED Requirements

### Requirement: 相似照片识别使用有边界的本地视觉信号

扫描器 MUST 在有界批次中遍历所选范围内全部非截图照片，并在较短创建时间窗口内，本地粗筛相似照片，并只对粗筛相似组执行候选复核。最终相似分组和内部质量比较 MUST 使用复核后的系统图片质量、Feature Print 与可用的人脸拍摄质量。推荐保留功能保持关闭，内部比较 MUST NOT 影响默认选择、批量选择、预计空间、任务文案或无障碍语义。当两张复核照片都具备可比较的 Vision Feature Print 时，扫描器 MUST 优先使用 Feature Print distance，而不是 pHash distance。当 Feature Print 不可用或不可比较时，扫描器 MAY 回退到保持完整构图且宽高比可比较的 pHash distance。

#### Scenario: Vision feature print 可用

- **WHEN** 两张非截图照片落在相似时间窗口内
- **AND** 粗筛将它们纳入同一候选子图
- **AND** 两张照片都有可比较的复核 Vision Feature Print
- **AND** 它们的 Feature Print distance 在复核阈值内
- **THEN** 扫描器将它们分组为相似照片复核组
- **AND** 不得展示推荐保留项，也不得自动删除照片

#### Scenario: Vision feature print 距离较远

- **WHEN** 两张复核照片有可比较的 Vision Feature Print
- **AND** 它们的 Feature Print distance 超出复核阈值
- **THEN** 扫描器不得再通过 pHash 兜底把它们保留在同一相似关系中

#### Scenario: Vision feature print 不可用

- **WHEN** 一张或两张复核照片缺少可比较的 Vision Feature Print
- **AND** 两张照片宽高比可比较
- **AND** pHash distance 在复核阈值内
- **AND** 两张照片落在相似时间窗口内
- **THEN** 扫描器可以将它们分组为相似照片复核候选

#### Scenario: 照片超出时间窗口

- **WHEN** 照片视觉信号相似但超出相似时间窗口
- **THEN** 扫描器不得将它们分组为相似连拍；跨时间精确重复必须另经本地资源摘要确认

#### Scenario: 相似组包含可比较的人脸照片

- **WHEN** 相似组成员具有复核后的 Vision 人脸拍摄质量结果
- **THEN** 内部质量比较必须以复核后的总体图片质量为主、人脸拍摄质量为辅
- **AND** 不得展示推荐保留结果，相似组默认零选择

#### Scenario: 人脸质量不可用

- **WHEN** 相似组成员没有可用的人脸拍摄质量
- **THEN** 内部质量比较必须继续使用复核后的总体图片质量，不得向用户展示推荐保留结果

#### Scenario: 复核拆分粗筛相似组

- **WHEN** 粗筛组内部分成员的复核 Feature Print 超出阈值
- **THEN** 最终分类必须移除不成立的相似关系或拆分为多个组
- **AND** 最终稳定分组 ID 必须由复核后的成员集合生成


#### Scenario: 跨时间的精确重复候选

- **WHEN** 两张非截图照片的拍摄时间相差超过 180 秒但被本地重复索引命中
- **THEN** 可以请求候选复核和本地资源摘要确认
- **AND** 缩略图或索引命中本身不得把它们升级为精确重复

### Requirement: 识别保持本地且有边界

视觉识别 MUST 本地运行，不得请求网络回源的 iCloud 图片或底层资源下载。粗筛、候选复核、Vision Feature Print、质量评估和精确重复确认 MUST 以有界批次覆盖所选范围内全部合资格照片及其派生候选；不得以静默全局截断代替完整扫描。扫描器 MUST 优先使用本地快速图片资源；当快速图片资源不可用但完整本地图片仍可读取时，扫描器 MUST 使用仍然禁止网络访问的高质量本地图片请求重试同一阶段。

#### Scenario: 快速图片资源可用

- **WHEN** Photos 能够从本地快速图片资源提供当前阶段所需图片
- **THEN** 扫描器使用该图片生成当前阶段视觉证据
- **AND** 扫描器不得再为同一照片和同一阶段执行高质量回退请求

#### Scenario: 快速图片资源缺失但完整本地图片可用

- **WHEN** Photos 的快速图片请求返回空结果或资源缺失错误
- **AND** 完整本地图片仍然可用
- **THEN** 扫描器必须使用禁止网络访问的高质量本地图片请求重试同一粗筛或复核阶段
- **AND** 成功读取的图片必须继续进入该阶段的 Feature Print 和质量评估

#### Scenario: 本地图像数据不可用

- **WHEN** Photos 无法在不允许网络访问的情况下通过快速和高质量请求提供粗筛图片
- **THEN** 跳过该资源的视觉粗筛
- **AND** 扫描继续处理其他可用资源

#### Scenario: 复核本地图像数据不可用

- **WHEN** 粗筛图片可用但 Photos 无法在不允许网络访问的情况下提供复核图片
- **THEN** 扫描器必须执行低置信度降级而不是请求网络
- **AND** 扫描继续处理其他复核候选

#### Scenario: 原始资源摘要不可用

- **WHEN** Photos 无法在禁止网络访问时提供精确重复确认所需的底层资源
- **THEN** 扫描器必须跳过该资源的精确重复确认
- **AND** 该失败不得中断视觉相似、质量评估或其他资源扫描

#### Scenario: 候选集合小于粗筛集合

- **WHEN** 粗筛完成并生成有限候选集合
- **THEN** `512px` 复核和原始资源摘要必须只处理该候选集合或其中更小的疑似重复子集
- **AND** 扫描器不得把所有已粗筛照片升级为高清或原始资源读取

#### Scenario: 超过旧视觉上限

- **WHEN** 合资格非截图照片超过旧 300/80 张上限
- **THEN** 继续后续批次，截图不占视觉预算
- **AND** 结果报告成功、缓存命中和不可读取数量，取消时保留旧会话
