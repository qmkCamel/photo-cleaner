## ADDED Requirements

### Requirement: 候选必须提供可判断内容的本地预览

App MUST 提供照片完整构图预览、缩放、前后切换和视频播放，并把预览与删除勾选分开。所有媒体请求 MUST 禁止网络；加载、失败和重试必须可见，离页必须取消请求。

#### Scenario: 查看照片或视频
- **WHEN** 用户点击预览
- **THEN** 照片可以缩放、切换，视频可以播放，预览不改变选择

#### Scenario: 本地媒体不可用
- **WHEN** Photos 不能提供本地资源
- **THEN** 展示不可用说明与重试，不下载 iCloud 内容

### Requirement: 用户可以确认并记住保留决定

App MUST 支持在预览内确认保留及整组确认保留，统一使用已有 ConfirmedKeepStore。已确认项不得留在复核箱或被选中删除，其他项不得自动变成删除选择。保留决定 MUST 本地持久化并可通过已有设置管理入口清除。系统推荐保留 MUST 保持关闭，不得新增旧推荐入口或平行的忽略记录。

#### Scenario: 预览内确认保留
- **WHEN** 用户在预览内确认一张照片保留
- **THEN** 该资源在所有引用中被保护并移出删除选择和复核箱，不影响其他资源

#### Scenario: 重扫已保留内容
- **WHEN** 用户整组保留后重新扫描
- **THEN** 已确认资源不再作为普通可删除候选，相似组可保留只读参考，清除确认记录后允许重新评估

#### Scenario: 恢复旧会话后保护状态发生变化
- **WHEN** 会话快照与最新确认保留记录不同
- **THEN** 必须以最新确认保留记录覆盖快照中的保护标记，并清理对应删除选择和复核箱引用
