## MODIFIED Requirements

### Requirement: 识别保持本地且有边界

视觉识别 MUST 本地运行，不得请求网络回源的 iCloud 缩略图下载。Vision feature print 生成和质量评估 MUST 只在视觉分类上限内、基于本地可用图像数据运行。扫描器 MUST 优先使用本地快速图片资源；当快速图片资源不可用但完整本地图片仍可读取时，扫描器 MUST 使用仍然禁止网络访问的高质量本地图片请求重试。

#### Scenario: 快速图片资源可用

- **当** Photos 能够从本地快速图片资源提供视觉分析图片
- **则** 扫描器使用该图片生成 feature print 和质量评估
- **并且** 扫描器不得再为同一照片执行高质量回退请求

#### Scenario: 快速图片资源缺失但完整本地图片可用

- **当** Photos 的快速图片请求返回空结果或资源缺失错误
- **并且** 完整本地图片仍然可用
- **则** 扫描器必须使用禁止网络访问的高质量本地图片请求重试
- **并且** 成功读取的图片必须继续进入 feature print 和质量评估

#### Scenario: 本地图像数据不可用

- **当** Photos 无法在不允许网络访问的情况下通过快速和高质量请求提供本地图像数据
- **则** 跳过该资源的 feature print 生成和质量评估
- **并且** 扫描继续处理其他可用资源
