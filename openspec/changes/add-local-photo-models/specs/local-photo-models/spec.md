## ADDED Requirements

### Requirement: 可替换的本地语义后端
系统 MUST 使用独立异步协议隔离业务与推理框架，支持 Qwen3.5-0.8B 和 Gemma 4 E2B 的固定模型配置；返回结构化观察、无法判断状态及来源，不返回删除决定。

#### Scenario: 切换模型
- **当** 用户切换模型并再次分析同一组照片
- **则** 分析使用选定版本并展示对应来源
- **并且** 不改变照片选择、确认保留或删除流程

#### Scenario: 模型输出无效
- **当** 模型输出不满足结构化契约
- **则** 显示可重试错误而非把文本解释为选择或删除指令

#### Scenario: 小模型短描述适配
- **当** Qwen 返回符合长度和单句文本边界的画面描述
- **则** 后端将其包装为统一观察对象，强制标记不确定
- **并且** 不修复畸形 JSON、不推断缺失的置信度或清理决定

### Requirement: 模型下载显式且完整
模型功能 MUST 默认关闭；下载 MUST 经用户显式操作，固定版本并校验文件后才标记就绪。照片推理 MUST 不联网，照片内容不得进入下载请求。

#### Scenario: 下载取消或失败
- **当** 下载未完成、被取消或校验失败
- **则** 不展示就绪状态，清理 staging，允许重试
- **并且** 不影响已安装模型与现有照片结果

#### Scenario: 移除模型
- **当** 用户移除指定模型
- **则** 只移除该模型的本地文件并刷新占用状态，不修改照片

### Requirement: 按需分析保持交互可用
分析 MUST 限定最多四张本地照片，提供动作局部进度、取消和失败恢复，不能阻塞无关导航，也不能自动开启推荐保留。

#### Scenario: 分析进行中
- **当** 用户开始分析
- **则** 禁止重复提交、保留照片网格与上次有效结果，仍可切换 tab

#### Scenario: 分组变化或退出
- **当** 用户切换分组、删除照片或退出分析所在页面
- **则** 取消旧任务并阻止过期结果回写

#### Scenario: 本地图像不可用
- **当** Photos 无法本地提供图片或访问被撤销
- **则** 显示可恢复错误，不下载 iCloud 照片且不以 fixture 冒充真实结果

### Requirement: 分层验证与截图证据
自动化 MUST 保持真实删除关闭，保留成功、进行中及失败恢复的命名截图，并把 fixture 交互验证、真实权重推理及真机性能验证分开记录。

#### Scenario: UI 自动化
- **当** 使用 fixture 后端验证交互
- **则** 测试报告说明 fixture 边界，截图通过 keepAlways 附件保留
