## ADDED Requirements

### Requirement: 复核会话必须支持恢复与事务式重扫

App MUST 本地保存复核箱、结果和用户决定，冷启动恢复可访问内容。重扫 MUST 只在成功后替换结果，取消或失败保留旧会话。复核箱记录满 30 天只能移除记录，不得删除 Photos 资源。

#### Scenario: 重启与取消重扫
- **WHEN** 用户加入复核箱后重启 App，或开始新扫描后取消
- **THEN** 原复核箱和可用旧结果仍存在
- **AND** 保存失败和损坏快照必须提供明确反馈

### Requirement: 失效路由与授权变化必须安全协调

App MUST 按唯一 ID 解析复核详情，并在前台和相册变化后校验权限与资源引用；不得把失去访问权限计为删除成功。

#### Scenario: 删除时首页保留详情
- **WHEN** 用户在复核箱删除当前详情所属分组的全部可清理项
- **THEN** 首页失效详情必须退出或显示失效空态，不能崩溃或误入其他组

#### Scenario: 用户缩小权限
- **WHEN** 用户在设置修改授权并返回
- **THEN** 页面必须刷新权限、候选和缩略图，并提供调整权限入口

### Requirement: 发布检查必须反映实际实现

隐私清单 MUST 声明 UserDefaults 的应用内用途。检查 MUST 允许明确限定的本地 SHA-256 用途，同时继续阻止网络和跟踪。CI MUST 执行 Python 和原生测试并上传结果包。

#### Scenario: 非破坏性回归
- **WHEN** 运行新增 UI 回归
- **THEN** 真实删除保持禁用，结果和恢复截图使用 keepAlways 保留
