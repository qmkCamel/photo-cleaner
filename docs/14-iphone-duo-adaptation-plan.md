# 14 iPhone Duo 全套适配方案

日期：2026-11-05。状态：**主体代码已实现，当前可执行自动化已通过；完整形态矩阵及未知删除结果恢复仍未完成，未发布**。

## 目标体验

外屏快速查看和选择，展开后利用额外空间同时看到任务列表与当前复核组；折叠、旋转和分屏时继续原来的操作，而不是重新开始。沿用当前品牌、三个 Tab、单主操作、保留保护与二次删除确认，不增加双图比较、独立第二屏或新清理能力。

## 核心决定

| 范围 | 方案 |
| --- | --- |
| 外屏/窄分屏 | 单面板、可滚动内容和可达动作；不假定底部永远有 Tab |
| 内屏/足够宽空间 | 首页任务列表与复核详情双栏；网格按空间调整，辅助功能大字号单列 |
| 系统控制区域 | 优先原生 Tab、导航、toolbar 与 sheet，按实际安全区/保留区避让 |
| 折叠/旋转/缩放 | 保留任务 ID、选择、范围草稿、预览与播放，不重复扫描或删除 |
| 危险操作 | 确认快照校验、单一提交、准确部分失败恢复；布局变化不是确认或取消 |
| 全页面覆盖 | 引导权限、扫描全链路、复核预览、复核箱确认、设置保留管理、帮助及模型页 |
| 支持范围 | 发布构建 SDK ≥ 27.1，保留 iOS 18 最低支持；不顺带发布 iPad/Mac 版 |

依据 [Apple 官方适配指南](https://developer.apple.com/iphone-duo/prepare/) 与其设计/开发讲解，详细来源和本地 SDK 核验见设计文档。物理尺寸不作为硬编码布局断点；先记录真实窗口再验证空间策略。本机已具备 Duo 模拟器与 iOS 27.1 runtime，但“有设备类型”不代表适配通过。

## 实施顺序

1. A：基线、安全区域、系统工具栏、矮窗口以及稳定操作所有者。
2. B：任务双栏、自适应网格、媒体和表单等全部页面。
3. C：连续切换、故障恢复、无障碍、旧机回归与发布证据。

常规测试全程禁用真实删除；用命名截图、切换录屏和请求次数断言共同验收。删除确认页已改为原生 Form，普通 iPhone 与原生 Duo 的专用文字可访问性检查通过；真实媒体、人工 VoiceOver 和跨设备项目仍不得沿用旧结果直接勾选。

## 本轮验证

实现记录与截图/录屏见 [Duo 验证记录](../iOS/TrueKeep/TestArtifacts/2026-11-05-duo/README.md)。布局实现包含动态网格、稳定的原生单/双栏导航、矮窗口滚动动作区、安全区/保留区适配、根级删除协调器和可滚动原生删除表单。

普通 iPhone 完整回归 199/199（144 单元 + 55 UI）通过，导出 115 张截图；原生 Duo 专项 3 通过、5 跳过、0 失败，另有删除返回/截图冒烟各 1/1 通过。Duo 的方向请求没有真正改变窗口，因此五项跨尺寸测试明确跳过，不计为适配通过。

Device Hub 的桌面控制权限尚未开放；当前运行覆盖不能代替外/内屏切换、分屏、半折叠、手动 VoiceOver 与真实媒体/性能验收。最低 iOS 18 的编译配置已核对，但本机没有可用的 iOS 18 runtime。

删除协调器的本轮保证覆盖同一进程内请求和重排；进程终止后的未知删除结果专项恢复仍未实现/验收，保留为未完成任务。
